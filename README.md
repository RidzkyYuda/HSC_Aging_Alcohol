This repository contains R codes used for the analysis of single-cell RNA-seq datasets from sorted murine Lineage- Sca-1+ cKit+ (LSK) cells as described in Yuda et al, 2025 manuscript (https://www.biorxiv.org/content/10.64898/2025.12.25.696246v1). The codes for scRNA-seq are written in R programming language and posted as .Rmd files inside directory Yuda-et-al_Murine_LSK_scRNA-seq_R_Codes. For the scATAC-seq R codes, we will post them in this repo later or can be requested in writing to the corresponding author's email. Thank you
